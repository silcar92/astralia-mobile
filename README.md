# Astralia Mobile

Repo reservado para la app Flutter de Astralia — **fase futura**, no arrancada todavía. La versión inicial del producto es web (`astralia-frontend`).

Cuando arranque esta fase: `flutter create .` y aplicar el mismo patrón de módulos que WiiGold Wallet (`lib/app/modules/<feature>/{bindings,controllers,views,widgets,repositories}`, `lib/app/common/` para el design system, `lib/app/data/` para la capa de datos). Ver `../astralia-backend/CLAUDE.md` y la memoria de proyecto `wiigold-architecture-reference` para el detalle completo.
